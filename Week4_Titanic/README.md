# Week 4 — Comprehensive Titanic Data Analysis (R)

This folder contains the final-week project materials for a four-week data analysis workflow. The analysis uses the Titanic passenger table bundled with base R, so no separate dataset download is required.

## Project aim
Explore survival patterns, prepare the data, communicate findings through charts, test associations, and build a logistic regression model to estimate survival outcomes.

## Files
- `Week4_Titanic_Analysis.R` — annotated R script for preparation, plots, association tests, and modeling.
- `Titanic_Final_Report.Rmd` — report source that can be knitted to Word.
- `outputs/graphs/` — charts generated by the R script.
- `outputs/tables/` — cleaned data, summary tables, tests, and model metrics generated when the script runs.

## How to run
1. Install R (and optionally VS Code with an R extension or RStudio).
2. Open the repository folder as your working directory.
3. Run `source("Week4_Titanic/Week4_Titanic_Analysis.R")`.
4. Open `Week4_Titanic/Titanic_Final_Report.Rmd` and click **Knit** to produce a Word document. Install `rmarkdown` and a LaTeX-free Word rendering setup as prompted if necessary.

The script installs missing packages from CRAN and writes its outputs into the `Week4_Titanic/outputs/` folder.

## Notes on interpretation
- The built-in Titanic object is a frequency table. The script expands its counts into passenger-level rows before plotting and fitting the model.
- Statistical tests describe associations in this dataset; they do not prove causation.
- Model metrics are calculated from a held-out test subset when the script runs. They are intentionally generated by the code rather than hard-coded into this README.
- This is a learning project based on a historical dataset. The results should not be treated as a general causal explanation of survival.

## Suggested report workflow
Run the script first so that all charts and tables exist. Then knit the report source to Word and review the generated results before submitting.
