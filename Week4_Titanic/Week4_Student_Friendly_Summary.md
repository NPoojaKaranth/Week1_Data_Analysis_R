# Week 4 — Final Report Notes (Student-Friendly Version)

This file adds a plain-language summary for the Week 4 Titanic project. It is an additional file; the existing Week 1–3 work and the current Week 4 script/report source are left unchanged.

## Introduction
For this project, I used the Titanic passenger dataset to practise the main steps of data analysis in R. I wanted to understand how data cleaning, graphs, and a prediction model fit together, rather than treating them as separate tasks. The dataset records whether passengers survived and includes details such as age, sex, and passenger class.

## What I did
First, I inspected the dataset and checked its structure and missing values. I then prepared the data for analysis and used graphs to make the main patterns easier to understand. Finally, I trained a logistic regression model and evaluated its predictions on a separate test set.

## Data preparation
Data is not always ready to analyse immediately. Missing values and variable formats need to be checked before making charts or training a model. In this project, the cleaning steps are documented in the R script so that another person can follow what was changed and why. Any imputation choices should be considered when interpreting the results, because replacing missing values can affect the patterns we see.

## Visualizations
The graphs help answer different questions:
- How many passengers survived compared with those who did not?
- Did survival rates differ across recorded passenger groups?
- What did the age and fare distributions look like?

A chart makes a pattern easier to notice, but it is still important to check the underlying counts and percentages. The figures describe this dataset and should not be treated as proof that one characteristic alone caused a particular outcome.

## Predictive modeling
I used logistic regression because survival is a two-outcome variable. The model estimates a probability, which is then converted into a predicted class using a threshold. Accuracy is useful, but it is not enough on its own, so the confusion matrix and additional measures such as precision, recall, F1 score, and ROC AUC should also be reviewed where available.

The actual results must be taken from the outputs generated by running the R script. I have not written fixed performance numbers here because they should reflect the dataset version and run used for submission.

## What I learned
This project helped me see that data analysis is a process: check the data, clean it carefully, explore it visually, build a model, and explain the results in context. I also learned that a model can make mistakes and that results should be reported honestly, including limitations.

## Limitations and future work
The Titanic data is historical and contains missing information. The model's results can change depending on how missing values are handled and how the data is split. For future work, I could compare logistic regression with a decision tree or random forest, use cross-validation, and study which features have the strongest association with survival.

## Conclusion
Overall, this project gave me practice with a complete R analysis workflow and with presenting technical findings in a way that is understandable to a general reader. The most important lesson is that graphs and model scores are only useful when the data preparation is transparent and the conclusions are careful.
